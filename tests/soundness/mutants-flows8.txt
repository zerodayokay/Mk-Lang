# Field-level loan sets' mutants, in two steps:
# step 1, per-field result sources, and step 2, per-field held
# sets for locals. The format is mutants.txt's,
# read with it by readMutantTable (every tests/soundness/mutants*.txt, IDs
# unique across the files). A row may patch one file of internal/borrow or
# internal/check, and names with `witness` the files of
# tests/soundness/witness/ it must flip: TestFlowsMutants (MK_SOUND=1)
# builds each mutant into a child test binary through go test -overlay and
# judges its witnesses there; each must be accepted, with nothing emitted
# (flows8Flipped: an error moved to another line or code is no flip).
# These rows are not run on the generator's sample by default
# (selectedMutants skips them). The per-field stratum (
# internal/corpus/soundfields.go, profile fields) was built to reach them:
# MK_SOUND_MUTANTS_GEN=1 with MK_SOUND_MUTANTS naming rows runs them there.
# It does not reach M-F8-W2-ret-union, whose one known kill
# the whole-body recheck rejects;
# S86 (soundholes.go) draws W2's crossed result in a
# function of its own, which that recheck does not reach.
#
# Rules of step 1 with no row:
# - Conservative in step 1, so no mutant is owed: a split temporary
#   becomes whole at a join (step 2's field-wise join is its sound
#   relaxation); a struct or record literal and some/ok split field-wise
#   (without them the value is whole, checked against every field). Borrow
#   splits a view with one more set, its rest; that split has its own
#   rows, M-P4-view-* in mutants.txt.
# - Unreachable in step 1, so no witness can show them: a store into a
#   split root makes it whole (addHeld), and put makes a root whole when
#   held grows with its vector unchanged. No store or field write reaches a
#   split temporary in step 1's lowering; they
#   are step 2's rules.
# - W1.mk has no row of its own: step 2 splits named locals, so W1's
#   rule "a whole binding is the union" does not hold, and W1.mk
#   is judged by step 2's rows below.
#

witness W2.mk fnlit-cross.mk
end

# Step 2, per-field held sets for locals. No narrowing of R11's
# first-level exemption for a clause-free callee is made: it would hold
# only in the direct callee, and a callee that
# is not narrowed (a generic, an extern, a fn value) one call further could
# move a loan between the fields of a local the caller kept split.
# The witnesses of such a narrowing stay:
# S2a-t2.mk and the S2-t2-*.mk files. Their notes say what each checks:
# the callee rules' witnesses are `ok`, and the caller rules' are E0505
# under M-RV2-1-excl-collapse.
#
#
# Load-bearing, with a row: the collapse at an exclusive whole borrow
# (M-RV2-1-excl-collapse: R11's first-level exemption lets any callee move a
# loan between the fields it reaches, and no store the caller sees records
# it) and the writable-by-type condition on a split kept across a shared
# whole borrow (M-RV2-a6-writable).
#
# Rules of step 2 with no row:
# - Conservative, so no mutant is owed: a view root never split
#   (S2-view-root.mk); a def of the whole root defining every field
#   element.
# - put making a split root whole when held grows with its vector unchanged
#   has no row of its own: it is the second half of two rules guarded twice
#   and M-F8-S2e-fieldloan-lost and M-F8-S2-d122-drop remove both
#   halves; the two halves are load-bearing jointly.
# - The union invariant (held is exactly the union of a split root's
#   fields) is checked on every put and every join by borrow's tests, the
#   soundness runs and TestFlowsWitnesses (borrow.SetSplitUnionCheck;
#   borrow's TestSplitUnionJoinChecked breaks a join).

# self-reach through a forwarding parameter (its argument's loans reach a Cell), so the whole check
